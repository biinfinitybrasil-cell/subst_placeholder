Instruções de uso

        
      


      

        
Esta tela substitui placeholders em códigos SQL em tempo real, mantendo uma memória interna do SQL original.


        
Como usar

        
    
          
  • Cole o SQL no editor ou carregue um arquivo .txt ou .sql.
    • 
          
  • Use placeholders no formato {{nome_do_campo}}.
    • 
          
  • Os campos aparecem automaticamente no painel da direita.
    • 
          
  • Ao preencher um valor, ele substitui o placeholder imediatamente.
    • 
          
  • Ao apagar o valor preenchido, o placeholder original volta para o código.
    • 
        


        
Tipos disponíveis

        
    
          
  • String: aplica aspas simples, por exemplo 'ABC'.
    • 
          
  • Número: mantém o valor sem aspas, por exemplo 15.
    • 
          
  • Placeholder: troca apenas o nome, por exemplo {{cliente}} para {{usuario}}.
    • 
        


        
Carregar e salvar valores

        
    
          
  • Carregue o SQL antes de carregar os valores, para que os placeholders já estejam identificados.
    • 
          
  • Use "Carregar valores (.json/.txt)" para importar um arquivo com os valores.
    • 
          
  • Se o arquivo for um array no formato exportado por "Salvar valores .json" ({"placeholder": "nome", "valor": "conteúdo", "formato": "String"}), os campos são preenchidos exatamente com o valor e o formato indicados.
    • 
          
  • Para qualquer outro arquivo .txt ou .json, o sistema busca no conteúdo, para cada placeholder já identificado, um trecho no formato "placeholder": "valor". Se encontrar, preenche o campo com o valor localizado, sempre no formato String.
    • 
          
  • Use "Salvar valores .json" para exportar os valores atuais de todos os placeholders identificados no formato estruturado.
    • 
        


        
Destaques visuais

        
    
          
  • No código escuro, placeholders ficam vermelhos e valores substituídos ficam amarelos.
    • 
          
  • No código claro, placeholders ficam em laranja escuro e valores substituídos ficam verdes.
    • 
          
  • Comentários iniciados com //, -- ou delimitados por /* e */ recebem cor própria conforme o tema do código.
    • 
          
  • O tema da tela e o tema da área de código são independentes.
